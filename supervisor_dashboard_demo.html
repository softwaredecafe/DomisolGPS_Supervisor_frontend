El tráfico puede explicar un retraso, pero no necesariamente una desviación. Si el vendedor sale del corredor permitido, el sistema genera alerta aunque exista tráfico, salvo que registre visita, autorización o cambio de ruta.

En producción, Google Routes API puede calcular rutas con tráfico y ETA. El sistema guarda esa estimación como evidencia al inicio y durante la ruta.
